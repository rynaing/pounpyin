# Pounpyin (ပုံပြင်)

**Their stories, kept in gold.**

Pounpyin is a keepsake-book service for Burmese families: one thoughtful question a week — in Burmese and English — answered by voice, woven into a hardcover book at year's end.

This repo hosts the launch landing page + waitlist.

- Live site: https://rynaing.github.io/pounpyin/
